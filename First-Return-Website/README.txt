FIRST RETURN, FIRST 10¢ — 可下载网站

使用方法
1. 先解压整个 ZIP，保持 index.html、style.css、app.js 和 assets 文件夹在一起。
2. 双击 index.html 即可在浏览器本地打开。不需要安装 Node.js，也不需要编译。
3. 发布时上传以上三个文件和完整 assets 文件夹。index.html 应位于发布目录根部。
   GitHub Pages：将文件放入仓库根部，Settings > Pages 中选择相应发布分支。
   如使用支持拖入文件夹的静态网站托管服务，直接上传解压后包含 index.html 的文件夹。

页面与交互
- 首页：About、活动介绍、游戏、活动包展示。
- 首页三张图片：在当前页展开 Check / Find / Return 说明，可关闭。
- 活动详情：时间、地点待定，FAQ 可展开，底部仅 Try a virtual return。
- Host Your Own Return：只展示 Coming soon；暂时没有详情跳转或申请。
- Donation：简单的 Coming soon 说明页，没有付款功能。
- Media：保留后续视频及媒体包位置，当前显示 Coming soon；两份插画可以下载。
- 游戏按钮：新标签页打开你的现有游戏，不包含另做的游戏版本。

后续编辑
- app.js：页面文字、活动日期地点及各板块内容。GAME_URL 为所有动态游戏按钮地址。
- index.html：页头、页尾及页头游戏按钮地址。游戏搬家时这里也要同步修改。
- style.css：颜色、字号、布局、手机适配。
- assets/：原有独立插画及图片，可用同名图片替换，勿删除仍被引用的文件。
- 图片为独立资源，文字和按钮是真实 HTML 元素；不是整张网站截图。
